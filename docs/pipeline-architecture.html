🔑 关键设计决策
  • recordId 粒度 ack：不用 binlog position 做 key（同位置可能有多条记录），而是用 taskName-batchId-rIdx 唯一标识每条 record
  • 同 partition 串行 apply：Hash Router 保证同主键进同一 partition，Worker 内用 foldLeft 串行，保证 UPDATE id=1 → UPDATE id=1 顺序不颠倒
  • 连续 checkpoint：OffsetCoordinator 的 getCommittablePosition() 只返回所有 partition 都已 applied 的连续位置，防止跨 partition 提前提交
  • Sink 成功 → Ack → Offset 前进：ApplyWorker 写入目标库成功 → markApplied → 连续 checkpoint 就绪 → commit → ack Debezium record → Debezium offset 持久化。任何一环失败，offset 不前进
  • FailFast + Stop：Apply 失败 → Future.failed → Pipeline Supervision.Stop，不跳过事件、不提前提交 offset
